Description

Assess a business-development opportunity and force an explicit decision.
Use when a possible pursuit, partnership, teaming arrangement, new market,
or inbound lead is described and the question is whether to chase it - or on
"should we pursue this," "is this worth it," "assess this opportunity,"
"bid or no-bid," "what do you think of this lead." Always ends in one
explicit call.


Instructions

SEPARATE THE TWO QUESTIONS - this is the core discipline
1. Is it REAL? Mission need, funding, acquisition path, timing.
2. Is it ATTRACTIVE FOR US? Technical fit, credible adjacency, competitive
   position, right-to-win.
An opportunity can be entirely real and still wrong for us. Say so plainly.

ASSESS ACROSS
mission need / funding / architecture / our position / technical fit /
acquisition path / competition / timing

WHICH FOOT IS IT ON?
- Foot A - Programs: design-in to a program of record, years-long, capture-
  weight discipline, relationship investment
- Foot B - Product: sell the existing catalog, weeks-months, lightweight
  qualification, protects margin
A pursuit advancing NEITHER foot is a distraction however attractive.

GREENFIELD OR DISPLACEMENT?
A funded, priced, incumbent-held line is a displacement play - entirely
different approach. Establish which before recommending anything.

SCORE THE BET
- Payoff on THREE axes, not one: revenue, EBITDA quality (product-economics
  vs labor-economics - services add revenue but dilute margin), and
  strategic value.
- Calibrated Pwin as a percentage, with reasoning.
- Asymmetry: is this a freeroll (big upside, capped downside - take it) or
  a fat tail (limited upside, ruinous downside - avoid even at good odds)?
- OUTSIDE VIEW: what's the base rate on pursuits like this? Trust the base
  rate over the inside story. This is the single strongest debias.

PRE-MORTEM
Assume it failed - why? Name the biggest kill-risk ("the monkey") and say
how to test THAT first and cheapest. Don't build the pedestal before you
know the monkey can be trained.

KILL CRITERIA
Set the specific condition and date that means walking away - written now,
while unemotional. This beats sunk-cost reasoning later.

END WITH ONE EXPLICIT CALL - never leave it unresolved:
PROMOTE / CONTINUE VALIDATION / MONITOR / DEPRIORITIZE / KILL

Then state what evidence would change the call. If nothing would, we're
advocating, not reasoning.

PUSH TOWARD KILLING THINGS. A portfolio of perpetually-open opportunities
is the failure mode being avoided. If evidence is thin, say kill. Ask
"would you pursue this if nobody were asking?"

ANTI-PATTERNS TO CATCH
resulting (judging the decision by the outcome) / sunk cost / motivated
reasoning under authority pressure / inside-view overconfidence / false
binary (bid vs no-bid ignores bid-smaller, team, shape-and-wait) / HiPPO

Deeper reference if loaded: "BD Strategy & Decision System - Method."
